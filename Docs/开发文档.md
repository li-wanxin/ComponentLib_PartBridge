# ComponentLib 维护平台 —— 开发文档

> Altium / Cadence 通用器件库维护工具 · 基于 GitHub 仓库 `li-wanxin/ComponentLib`
> 更新日期：2026-11-16 · 版本 v0.4

---

## 1. 项目概述

以 `ComponentLib.mdb`（Access 数据库，40 张业务表 / 2067+ 记录，标准 18 字段）为核心的 Windows 桌面维护工具，目标是把"查立创 SN → 字段带出 → 分类匹配 → 确认入库 → 规格书/3D 模型落盘"的全过程自动化，UI 架构与 lab-console 项目一致（HTML/CSS + pywebview）。

## 2. 运行方式

```
run.bat  →  python app/desktop.py
```

- pywebview（Windows WebView2）原生窗口，本机回环 127.0.0.1 随机端口，外部不可访问
- pywebview 不可用时自动回退浏览器模式
- 测试库：`test-lib/ComponentLib.mdb`

## 3. 架构

| 模块 | 职责 |
|---|---|
| `app/server.py` | stdlib ThreadingHTTPServer + JSON API；全局 RLock 保护 pyodbc；规格书/3D 模型落盘 |
| `app/lcsc.py` | 立创商城 SN 查询客户端（多镜像 + 商品页增强 + 3D 模型解析） |
| `app/db.py` | pyodbc + ACE ODBC 直连 .mdb；查重/插入/更新/每日备份 |
| `app/conventions.py` | 库目录约定：路径建议（AltiumSchLib/AltiumPcbLib/StepModel）、内部编码、表映射 |
| `app/desktop.py` | pywebview 窗口 + js_api（pick_db_file / pick_datasheet_file / open_url / reveal） |
| `app/web/` | index.html + style.css + app.js（@token 双主题、276px 侧栏、卡片布局） |

## 4. 已实现功能

### 4.1 器件库浏览
- 左侧 40 张表列表（含记录数），全字段模糊搜索
- 表格行点击 → 记录详情（分组展示：物料类别/物料信息/供应商/数据文档/器件封装/修改日期）
- 详情面板下方 **检测结果块**：信息完整度进度条（百分比 + 三档配色）+ 分条检查（必填项/模型字段/规格书）
- 记录编辑（✎ 修改）：自定义下拉（同表已有值，非原生 datalist），修改日期自动更新为当天

### 4.2 添加物料
- **SN 查询**：`C25704` 等 → 自动带出 12 个字段（型号/生产商/值/精度/描述/供应商/链接等）
- 分类自动匹配（tags → DB 表名，下拉可改），封装缺失用商品页 encapStandard 兜底
- 描述升级：立创商品页 productDescEn → productIntroEn → productNameEn 三级兜底
- **规格书落盘**：目标路径 `DataSheet/表名前缀/器件型号.pdf`；支持"替代文件"（本地 PDF 复制更名）与"预览"（浏览器打开网页链接）；入库时自动下载（已存在保留）
- **3D 模型下载**：从立创官方库下载 STEP 到 `StepModel/<封装>.STEP`（见 4.3）
- **检测结果面板**：独立面板（写入预览下方），含信息完整度进度条与分条检查项（✓ 通过 / △ 提醒 / ✗ 阻断），必填缺失或重复时禁用写入按钮
- 新增分类表（18 标准字段）、新增具体类别

### 4.3 3D 模型下载链路（摘自 LCSC3D）

```
器件 result.packageDetail.dataStr (JSON)
  → shape 数组找 SVGNODE~ 节点 → attrs.uuid (c_etype 空/outline3D)
  → 兜底 head.uuid_3d
  → STEP 直链: modules.lceda.cn/qAxj6KHrDKw4blvCG8QJPs7Y/{uuid}（国内优先）
              modules.easyeda.com/...（国际备用）
  → 校验响应含 ISO-10303-21 文件头
  → 备用链: api/components/{uuid_3d} → docType=16 记录 → dataStr.head.uuid → 再下载
  → 落盘 StepModel/<封装>.STEP（已存在保留原文件）
```

- PC3D Path 行实时存在性检测（400ms 去抖，Path/Ref 输入均触发），已存在显示绿色 ✓ 徽标
- 三个路径文本框（Library/Footprint/PCB3D Path）统一缩短 + 尾部恒定预留位（56px），长度不随徽标有无变化

## 6. 库文件生态调研结论（2026-11-16）

### 6.1 Altium SchLib / PcbLib —— 读/写/改可行 ✅

- SchLib/PcbLib 本质为 **OLE 复合文档（CFBF）**，Python `olefile` 可读
- **LCSC3D 源码（github.com/Travelerrrrrr/LCSC3D）已实现全链路，可直接摘取**：
  - `library_merge.py`（660 行）：`LibraryIndex` 读现有库索引；**`append_library(original, generated, 'SCHLIB'/'PCBLIB')` 向现有库追加元件并保留原 compound storage**；`patch_parameters()` 批量改字段参数
  - `altium.py`（409 行）：从 EasyEDA 几何生成原生 SchLib/PcbLib 记录（坐标约定 1 unit = 10 mil = 100000 AD raw units）
  - `compound_storage.py`：Windows COM（StgCreateDocfileOnILockBytes）写 CFBF，仅 Win10/11
- 备选生态：**AltiumSharp**（C#，Apache-2.0，完整读+写+改+渲染）、**pyAltiumLib**（pip，仅读+SVG 渲染）

### 6.2 Cadence OLB / DRA / PSM —— 只读可行，写回无开源 ⚠️

- **OLB**（原理图符号库）：同为 CFBF。**OpenOrCadParser**（C++20，MIT，github.com/Werni2A）可解析 DSN/OLB/OBK、提取符号流；仅只读（README 中 modifying/writing 均为问号状态）。官方交换路径：Capture **XML 导出**（`olb.xsd` 在 Cadence 安装目录 `tclscripts/capDB/`）+ **Tcl/Tk 自动化**；orlib2ki/pyorlib2ki 可转 KiCad
- **DRA/PSM**（PCB 封装）：**OpenAllegroParser**（C++17，MIT，已归档停更）支持 `.brd/.dra/.psm/.ssm/.fsm/.osm/.bsm/.pad` 只读解析 → XML 导出；部分 padstack 动态结构需暴力搜索参数集；**写回无任何开源实现**

### 6.3 结论

1. **Altium 侧全链路可做**：摘 LCSC3D 的 `easyeda_import + altium.py + library_merge.py`，实现"查 SN → 生成符号 → 自动追加进对应 SchLib/PcbLib → 回写 Library Ref/Footprint Path"
2. **Cadence 侧降级为只读管理**：解析做清单/预览可以（C++ 外部工具或官方 XML 导出），写回不自研——生成 OrCAD XML 或由用户用官方 Tcl/SKILL 导入

## 7. Cadence 封装自动生成方案（datasheet → 各层绘制）✅ 可行

**核心思路：Geometry 计算放 Python，绘制执行放 SKILL（Cadence 官方接口），避免直接写 .psm 二进制（无开源方案）的死路。**

### 7.1 Allegro SKILL 全程序化建封装（已验证 API 存在）

```skill
axlPadStackCreate("R0402_SMD" 'RECTANGLE list(padL padW))   ; 焊盘（含 Top/Paste/Mask 各层）
axlDBCreatePin(...)                                          ; 放引脚
axlDBCreateLine(顶点 线宽 "Package Geometry/Silkscreen_Top")  ; 丝印
axlDBCreateLine(... "PACKAGE GEOMETRY/ASSEMBLY_TOP")         ; 装配层
axlDBCreateLine(... "PACKAGE GEOMETRY/PLACE_BOUND_TOP")      ; 占位框
axlCmdRegister("gen_fp" 'gen_fp)                             ; 注册为 Allegro 命令（插件）
axlShell("dlib")                                             ; 脚本批处理导出 .psm
```

商业工具 PCBL Library Expert 即此路线（输入 datasheet 尺寸 → 输出 Allegro 可用文件）。

### 7.2 尺寸参数来源（两档）

| 方案 | 说明 | 推荐 |
|---|---|---|
| 参数化生成 | 人工从 datasheet 抄 4~5 个尺寸（引脚数/pitch/体宽 E,D/引脚长 L/引脚宽 b）→ **IPC-7351B 公式**自动算焊盘（Toe/Heel/Side goal，密度 L/N/M 三档） | ✅ 推荐 |
| PDF 直读 | 矢量 PDF 可 PyMuPDF 提取线段+标注；扫描件需 OCR+CV；厂商图纸风格差异大 | 半自动（文本层预填+人工确认） |

开源 IPC-7351B 方程实现（可摘）：
- **LandForge**（Python，MIT）：完整方程 + JEDEC 封装尺寸库，633 封装机器验证
- **QEDA**（Node.js）：Chip/Dual/Quad/QFN/BGA/SOT/TO 等十几族
- **Footag**（C 库）：设计为可嵌入、自定义输出格式

### 7.3 落地架构

```
ComponentLib 工具 (Python)
  ├─ 封装家族识别（已有 PKG_TO_PCB_FAM：SOT/QFN/SOP/DIODE-SMA...）
  ├─ 尺寸表单（4~5 项，可从 datasheet PDF 半自动预填）
  ├─ IPC-7351B 方程（摘 LandForge/QEDA）→ 算 padstack + 各层几何
  └─ 输出 <封装名>.il SKILL 脚本
        ↓ 用户在 Allegro 中 script 加载运行
     自动画完各层 → 另存 .dra → axlShell 导出 .psm
```
